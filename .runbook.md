# Base Core Market Upgrade Runbook

This runbook covers full end-to-end execution for the Base core market upgrade:
- Oracle-family routing (`price/rate/smartdata/macro/equity`)
- 5 new market types
- UUPS upgrade + selector/module wiring
- Post-upgrade verification and rollback posture

Assumptions:
- Repo root: `/home/asyam/dev/Project/RetroPick/V1/contract`
- Foundry + `openzeppelin-foundry-upgrades` plugin already installed
- All commands run from repo root unless noted

## 2) Roles and controls

- `ADMIN`:
  - Must be secure multisig on testnet/mainnet
  - Owns selector wiring and oracle adapter setters
- `WORKER`:
  - Keeper/ops authority for lifecycle operations
- `TREASURY`:
  - Fee receiver

Operational policy:
- Never broadcast from a hot private key directly
- Use Foundry keystore account (`--account <KEYSTORE_NAME>`)
- Use `EXPECTED_CHAIN_ID` on every deploy/upgrade script run

## 7) Post-deploy / post-upgrade verification checklist

Run after each broadcast on target chain.

## 7.1 Core config reads

```bash
cast call "$PROXY_ADDRESS" "configInitialized()(bool)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "admin()(address)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "treasury()(address)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "workerAuthority()(address)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "priceOracle()(address)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "rateOracle()(address)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "smartDataOracle()(address)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "macroOracle()(address)" --rpc-url "$RPC_URL"
cast call "$PROXY_ADDRESS" "equityOracle()(address)" --rpc-url "$RPC_URL"
```

All must match intended addresses.

## 7.2 UUPS implementation check

Using script logs:
- Confirm new implementation address differs from prior impl on upgrade
- Confirm proxy address unchanged on upgrade

## 7.3 Selector wiring integrity

Verify representative selectors resolve to expected module:
- `upsertTemplate(...)`
- `openEpoch(...)`
- `resolveEpoch(...)`
- `setRateOracle(address)`
- `setSmartDataOracle(address)`
- `setMacroOracle(address)`
- `setEquityOracle(address)`

Use dispatcher getter:
- `getSelectorModule(bytes4)` on `MarketEngineDispatcher`

## 7.4 Live smoke test (at least 1 template per oracle family)

For each class:
- Upsert template with correct `oracleClass`
- Initialize market
- Open -> lock -> resolve a single epoch
- Confirm settlement path succeeds and no unexpected halt/revert

Minimum template matrix:
- `CHAINLINK_PRICE`: legacy threshold/direction
- `CHAINLINK_RATE`: `StakingAPR` or `VolatilityBand`
- `CHAINLINK_SMARTDATA`: `NAVThreshold`
- `CHAINLINK_MACRO`: `MacroEvent`
- `CHAINLINK_EQUITY`: one threshold template using equity feed

---

## 8) Rollback and incident posture

If issue is selector-specific:
- Use modular rollback script (`script/modular/90_Rollback.s.sol`) for selector remap rollback.

If issue is implementation-wide:
- Pause program (admin)
- Upgrade back to prior validated implementation
- Re-run verification checklist before unpause

Emergency controls:
- `pauseProgram(true)` immediately on critical anomaly
- Do not unpause until:
  - root cause identified
  - fix deployed
  - full smoke checks pass
