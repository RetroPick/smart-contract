# RetroPick Market Types (Consolidated Model)

This document reflects the **breaking simplification** where threshold-like variants were collapsed.

## New Canonical `MarketType` Set

The protocol now uses:

1. `Direction`
2. `Threshold`
3. `RangeClose`
4. `Velocity`
5. `Ladder`
6. `Convergence`
7. `Composite`
8. `Corridor`
9. `Cascade`

All threshold-like business domains now route through `Threshold` plus template metadata (`oracleClass`, labels, and config fields).

---

## Breaking Migration Mapping (Old -> New)

- `Anchor` -> `Threshold` (use `anchorPriceE8` as effective threshold)
- `VolatilityBand` -> `Threshold` + `oracleClass=CHAINLINK_RATE`
- `StakingAPR` -> `Threshold` + `oracleClass=CHAINLINK_RATE`
- `NAVThreshold` -> `Threshold` + `oracleClass=CHAINLINK_SMARTDATA`
- `MacroEvent` -> `Threshold` + `oracleClass=CHAINLINK_MACRO`
- `BitcoinIRC` (threshold mode) -> `Threshold` + `oracleClass=CHAINLINK_RATE`
- `BitcoinIRC` (direction mode) -> `Direction` + `oracleClass=CHAINLINK_RATE`

Unchanged families:
- `Velocity`, `Ladder`, `Convergence`, `Composite`, `Corridor`, `Cascade`, `RangeClose`, `Direction`

---

## Why This Simplification Works

### Replaced by `Threshold`
These all settled using threshold-style logic already:
- Anchor-style framing (now threshold with `anchorPriceE8` fallback),
- vol/rate/nav/macro category markets (now threshold + oracle class),
- BitcoinIRC threshold mode.

### Not replaced by `Threshold`
These retain dedicated types because logic is structurally different:
- `Velocity`: uses lock+resolve checkpoints and magnitude buckets.
- `Ladder`: custom ladder liability/payout math.
- `Convergence`: dual-feed spread open/close with tolerance and possible void.
- `Composite`: multi-feed logical aggregation.
- `Corridor`: path-dependent high/low breach detection.
- `Cascade`: level-break count over high/low path with directionality.

---

## Operational Selection Guide

- Use `Direction` for up/down from lock to resolve.
- Use `Threshold` for all fixed-level binary questions (price/rate/nav/macro domains).
- Use `RangeClose` for N-bucket close landing.
- Use `Velocity` for percentage move bucketing.
- Use `Ladder` for tiered payout buckets.
- Use `Convergence` for two-feed spread convergence/divergence.
- Use `Composite` for AND/OR/Majority feed logic.
- Use `Corridor` for in-band vs upper/lower breach.
- Use `Cascade` for count of crossed levels.
