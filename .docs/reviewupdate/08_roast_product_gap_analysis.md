# RetroPick Roast: Product Gap Analysis

## Verdict

RetroPick’s biggest risk is not technology; it is strategic self-contradiction—trying to be a deterministic engine, a broad global market platform, and a mainstream product at once before proving one wedge.

## The worst issues

## 1) Strategy diffusion (too many identities)
**What’s wrong:** Product narrative still tries to satisfy too many categories and user archetypes simultaneously.  
**Why it matters:** Teams that optimize for everyone at launch usually fail to achieve PMF in any segment.  
**What good looks like:** One launch identity: deterministic recurring event contracts for a narrow, repeated use case.

## 2) Capability-promise mismatch
**What’s wrong:** Some advanced market stories can be misread as launch-ready when underlying lifecycle/oracle constraints limit safe rollout.  
**Why it matters:** Promise gaps create trust loss faster than feature gaps in money products.  
**What good looks like:** Public roadmap mapped strictly to Now/Next/Later feasibility and operator constraints.

## 3) UX trust debt
**What’s wrong:** Deterministic settlement is a core advantage, but if users cannot easily read and verify lock/close/formula outcomes, the advantage is invisible.  
**Why it matters:** Invisible trust is non-existent trust for mainstream users.  
**What good looks like:** Every market card and post-settlement state explains outcome logic in plain language with data provenance.

## 4) Liquidity fragmentation risk
**What’s wrong:** Innovation pressure can push too many templates before behavior concentration is proven.  
**Why it matters:** Fragmented liquidity weakens user outcomes, retention, and perceived product quality.  
**What good looks like:** Template portfolio governance with hard caps and kill rules for underperforming markets.

## 5) Mainstream expansion sequencing risk
**What’s wrong:** Non-crypto expansion is strategically attractive but likely to fail without onboarding and language adaptation built into core UX.  
**Why it matters:** Premature mainstream push inflates CAC and hides PMF signals under noisy acquisition.  
**What good looks like:** Crypto wedge proof first, then controlled mainstream pilots with utility-specific journeys.

## Common crypto product sins detected

- **Complexity worship (moderate risk):** advanced market taxonomy can become strategy theater if not tied to shipped behavior.
- **No retention loop (partial risk for non-crypto):** crypto loop is clear; mainstream loop is still hypothesis-heavy.
- **Bridge to nowhere (early warning):** innovation breadth can outpace GTM and user behavior evidence if unmanaged.
- **Jargon overload (moderate risk):** architecture-heavy language can obscure user value.

## UX red flags to preempt now

- Wallet gate before value preview.
- Weak transaction preview and settlement explanation surface.
- Missing error recovery and post-transaction clarity.
- No beginner pathway for non-crypto users.
- Limited shareable state/deep links for creator-led growth.

## Fix these now

1. **Highest-impact fix: lock the launch identity.**  
   Publicly commit to one wedge (deterministic recurring templates), one core segment, and one success metric set for 90 days.

2. **Easiest win: ship trust UX before new templates.**  
   Add explicit market rule cards and post-resolution proof cards across all launch templates.

3. **Existential fix: enforce portfolio governance.**  
   Introduce hard template caps, weekly kill criteria, and a rule that no new family ships without retention and concentration thresholds.

## Final blunt guidance

RetroPick does not need more ideas right now. It needs ruthless execution discipline around one wedge, one narrative, and one repeat behavior loop. Win that first, then expand.
