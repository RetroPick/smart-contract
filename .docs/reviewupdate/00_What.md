# RetroPick Strategy Review Pack

This folder contains the complete product and business strategy review for RetroPick, grounded in current smart contract capabilities and market positioning constraints.

## Read this in order

1. [`01_executive_product_thesis.md`](./01_executive_product_thesis.md)  
   Canonical strategic narrative, target segments, and positioning baseline.

2. [`02_capability_to_market_map.md`](./02_capability_to_market_map.md)  
   What can be launched now versus next/later based on contract reality.

3. [`03_competitive_landscape.md`](./03_competitive_landscape.md)  
   Direct competitors, substitutes, crowdedness, and differentiation strategy.

4. [`04_tam_sam_som.md`](./04_tam_sam_som.md)  
   Top-down and bottom-up market sizing with low/base/high scenarios.

5. [`05_pmf_and_validation_plan.md`](./05_pmf_and_validation_plan.md)  
   PMF hypotheses, KPI tree, experiment cadence, and go/pivot/no-go gates.

6. [`06_innovation_opportunity_map.md`](./06_innovation_opportunity_map.md)  
   Expansion of current idea seeds into ranked crypto and non-crypto opportunities.

7. [`07_execution_roadmap_90_180_365.md`](./07_execution_roadmap_90_180_365.md)  
   Milestone plan with phase gates, risk controls, and execution cadence.

8. [`08_roast_product_gap_analysis.md`](./08_roast_product_gap_analysis.md)  
   Brutal stress-test of weaknesses, scorecard, and immediate fix priorities.

9. [`09_board_memo.md`](./09_board_memo.md)  
   Single-file board memo: thesis, hard risks, market sizing, PMF gates, and 90-day CEO priorities.

## Quick orientation

- If you need **strategy direction first**, start with `01` then `07`.
- If you need **technical feasibility first**, start with `02` then `06`.
- If you need **fundraising/business narrative**, start with `01`, `03`, and `04`.
- If you need **operator execution**, start with `05` and `07`.
- If you need **hard critique before execution**, read `08` immediately after `01`.
- If you need **one document only**, read `09`.

## What this pack optimizes for

- Consistency with current engine constraints.
- PMF-focused decision making over generic market storytelling.
- Practical execution sequence (wedge -> prove -> expand).
